Integrá tu tienda Woocommerce a Correo Argentino para optimizar la gestión de tus envíos PAQ.AR en todo el país.

== Description ==

**Con el plugin de Correo Argentino vas a poder:**
* Realizar la Integración con MiCorreo o API 2.0 de acuerdo a tus necesidades.
* Ofrecer a tus clientes Envíos Expreso o clásico a sucursal y domicilio en todo el país.
* Brindar envíos gratuitos según tu estrategia comercial.
* Aplicar descuentos o recargos en tus envíos para adaptar tus costos de manera flexible.
* Realizar el seguimiento y gestión de todos tus envíos desde un solo lugar, de forma simple y eficiente.
* Gracias al cotizador online de MiCorreo vas a poder conocer los costos de envío en tiempo real directamente desde la plataforma.


**Pasos previos:**
Para operar con **MiCorreo**: Accedé con tu usuario y contraseña. En caso de no tener una, podés crearla ingresando en: https://www.correoargentino.com.ar/MiCorreo/public/

Para operar con la **Api PAQ.AR 2.0**: Ingresá el “Agreement”, “Apikey” previamente otorgado por un ejecutivo de cuentas. En caso de no tener asignado uno, podes contactarnos ingresando en: https://www.correoargentino.com.ar/MiCorreo/public/contact

== Installation ==

1. Debés subir el plugin a /wp-content/plugins/.
2. Actívarlo desde el menú «Plugins» en WordPress.
3. Configurar tus credenciales y ajustes en WooCommerce → Ajustes → Envíos → Correo Argentino.

== Frequently Asked Questions ==

= ¿Tengo que registrarme previamente? =
Si,No te preocupes, es un proceso simple y rápido. Solo tenés que ingresar en https://www.correoargentino.com.ar/MiCorreo/public/ y completar el formulario en 2 pasos y listo, ya podés empezar a usar MiCorreo. Recordá que necesitás tener una cuenta activa para operar con el plugin de Correo Argentino.

= ¿Cómo integro mi tienda WooCommerce con Correo Argentino? =
Para realizar la integración podés ingresar en https://www.correoargentino.com.ar/MiCorreo/public/mi-correo#, donde vas poder descargar el manual con el paso a paso que te guiará durante todo el proceso.

= ¿Puedo ofrecer envíos gratuitos? =
¡Sí! Podés definir un monto mínimo de compra para que el envío gratis se active automáticamente

= ¿Puedo aplicar un recargo/descuento a mis envíos? =
Sí. Podés establecer un importe maximo o mínimo para tus pedidos de manera simple.

= ¿Qué modalidades de envíos puedo ofrecerles a mis clientes? =
Podés ofrecer a tus clientes diferentes modalidades de envío según sus necesidades: envíos clásico o expreso, tanto a domicilio como a sucursal, para que elijan la opción que les resulte más cómoda y conveniente al momento de recibir su compra.
